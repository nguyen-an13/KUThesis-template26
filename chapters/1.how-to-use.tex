\chapter{How to Use This Template}


\section{Introduction}
This document explains how to use the \texttt{KUThesis} \LaTeX{} template for Korea University thesis/dissertation submissions, following the official 2022 Korea University graduate school guidelines. This lab's copy has been adapted from the original \texttt{KUThesis2022} template by Suhyeon Lee (\url{https://github.com/hyeonleee/KUThesis2022}) and is kept as an English-only, internal starting point: fill in your own details and replace the placeholder chapters with your real content.

\section{Key Features}
The template lets you switch between a master's thesis or a Ph.D. dissertation, double-sided or single-sided printing, and a \textbf{\textcolor{red}{library submission format}}, so you can avoid repeating formatting work during writing, examination, and submission.

\section{Compiling}
This class has been tested with \texttt{pdflatex} (Overleaf and local TeX distributions such as TeX Live/MacTeX both work).

\section{Other Ways to Compile}
Any TeX Live 2013 or later distribution should work. On Unix-like systems, run \texttt{make}; on Windows, run \texttt{make.bat}. Use \texttt{make clean} or \texttt{clean.bat} to remove the generated build files. Keeping backups of your work is strongly recommended.


\section{Project Files}
This template includes the following files:
\begin{itemize}
  \item Class file: \texttt{KUThesis.cls}
  \item Main file: \texttt{thesis.tex}
  \item English abstract: \texttt{abstract/abstract.tex}
  \item Korean abstract: \texttt{abstract/abstract-kr.tex} (required by regulation even for an English-language thesis - see \texttt{krabst} below)
  \item Acknowledgement (사사): \texttt{acknowledgement.tex}
  \item Dedication page (감사의 글, optional): \texttt{dedication.tex} - enable with \verb|\includeDedication|
  \item Preface (서문, if necessary): \texttt{preface.tex} - enable with \verb|\includePreface|
  \item Nomenclature (기호설명, optional): \texttt{nomenclature.tex} - enable with \verb|\includeNomenclature|
  \item Bibliography database: \texttt{library.bib}
\end{itemize}

\section{Class Options}
You can pass the following options to \verb|\documentclass[...]{KUThesis}|:

\subsection{Available Options}
\begin{itemize}
  \item \texttt{doctor} / \texttt{master}: Ph.D. dissertation or Master's thesis
  \item \texttt{final} / (omit for draft): final submission version or a work-in-progress draft
  \item \texttt{library}: formats the document for digital library submission
  \item \texttt{twosides} / \texttt{oneside}: double-sided or single-sided printing
  \item \texttt{krabst}: generates the Korean abstract page (required by regulation, even for an English-language thesis)
  \item \texttt{science} (default) / \texttt{arts}: (master's only) labels the degree ``Master of Science'' or ``Master of Arts''
  \item \texttt{asym}: adjusts the binding-side margin for print shops that prefer an asymmetric gutter
  \item \texttt{chapterinline} (default) / \texttt{chapterstacked}: ``Chapter 1. Title'' on one line, or ``Chapter 1'' / ``Title'' on two lines
\end{itemize}

\subsection{Examples}

\begin{itemize}
    \item \verb|[doctor, final, twosides, krabst, library]|: Ph.D. dissertation, library submission, double-sided, with Korean abstract (recommended)
    \item \verb|[master, final, twosides, krabst]|: Master's thesis, final bound copy, double-sided, with Korean abstract (recommended)
    \item \verb|[master, final, oneside]|: Master's thesis, final version, single-sided
    \item \verb|[doctor, oneside]|: Ph.D. dissertation, single-sided, draft
\end{itemize}

\section{Chapter Heading Style}
Chapters in this template (this one included) are started with a plain \verb|\chapter{Title}| (automatic numbering). How the heading itself looks is controlled by a class option:
\begin{itemize}
  \item \texttt{chapterinline} (default): ``Chapter 1. Title'' on a single line
  \item \texttt{chapterstacked}: ``Chapter 1'' and ``Title'' on two separate lines (plain \LaTeX{} report style)
\end{itemize}
Pick whichever style you prefer in \verb|\documentclass[...]{KUThesis}|; it applies to every \verb|\chapter| in the document automatically, so you never need to format individual chapter headings by hand.

\section{What You Need to Edit}
To use this template for your own thesis/dissertation, update the following in \texttt{thesis.tex}:
\begin{itemize}
  \item \texttt{\textbackslash title}, \texttt{\textbackslash author}, \texttt{\textbackslash advisor}: title, your name, and your advisor's name
  \item \texttt{\textbackslash graduateSchool} / \texttt{\textbackslash department}: your department and graduate school
  \item \texttt{\textbackslash graduateDate}, \texttt{\textbackslash submitDate}, \texttt{\textbackslash approvalDate}: graduation, submission, and examination-approval dates
  \item \texttt{\textbackslash referee}: your committee members' names
  \item \texttt{\textbackslash keywords}: the keywords shown at the bottom of the abstract
  \item \texttt{abstract/abstract.tex} and \texttt{abstract/abstract-kr.tex}: your English and Korean abstracts
  \item \texttt{dedication.tex}, \texttt{preface.tex}, \texttt{nomenclature.tex} (all optional): only needed if you enable the matching \verb|\include...| command
  \item Replace the placeholder chapters (this one included) under \texttt{chapters/} with your actual content
\end{itemize}

If the automatic line breaks in \texttt{KUThesis.cls} look awkward for a particularly long name, title, or department, you may need to manually adjust line breaks (\textbackslash\textbackslash) or font sizes in the relevant macro.
